# OR-amplification talk

Slides for explaining the per-head ordering work to the research group.

## Output

- `OR_amplification.pptx` — 28 slides, 16:9
- `SCRIPT.md` — speaker script, one section per slide, with anticipated questions at the end

Read `SCRIPT.md` alongside the deck. Its headings are numbered to match the slides exactly, so
`## 14 — masked vs sorted` is what to say on slide 14.

## Regenerating

The figures and the deck are generated by script so they can be refined without hand-editing
PowerPoint. From this directory:

```bash
.venv/bin/python figs_concept.py    # 01-05  motivation, serialization, windows, diversity
.venv/bin/python figs_impl.py       # 06-09  masked vs sorted, tiles, LSE merge, pipeline
.venv/bin/python figs_results.py    # 10-14  density, cost, timings, block sweep, compile trap
.venv/bin/python build_deck.py      # assembles OR_amplification.pptx
```

The training-comparison figure pulls live from Comet, so it needs the **project** python
(which has `comet_ml`) rather than this venv:

```bash
../../../../../../.pixi/envs/default/bin/python figs_training.py   # 15  training curves
```

Re-run that one and rebuild to refresh the slide as the runs progress.

## Layout of the code

| file | what it holds |
|---|---|
| `theme.py` | the palette, fonts and figure sizing — change the look in one place |
| `figs_concept.py` | the "why" diagrams |
| `figs_impl.py` | the "how" diagrams (the load-bearing ones) |
| `figs_results.py` | measured numbers; all values live in `MEASUREMENTS` at the top |
| `figs_training.py` | live Comet curves |
| `build_deck.py` | slide content declared as data in `build()`; helpers above it |

Every figure function is independent, so you can re-run a single one while tweaking it:

```bash
.venv/bin/python -c "import figs_impl; figs_impl.fig_tiles()"
```

## Colour convention

Kept consistent across every figure so the audience can read them without a legend:

- **blue** — the baseline / today's model / flash
- **amber** — OR amplification, the new thing (also the deck's accent)
- **red** — the expensive or incorrect option (`masked`)
- **green** — the cheap or correct option (`sorted`), and confirmations

## Notes on the content

Numbers come from the measurements recorded in `../step4-5-plan.md` (§0d, §0f) and
`../1. Per-Head Ordering.md`. If the benchmark is re-run, update `MEASUREMENTS` in
`figs_results.py` — that is the only place they are written down in this folder.

`.venv/` is an isolated environment holding `python-pptx`; the project environment is untouched.
